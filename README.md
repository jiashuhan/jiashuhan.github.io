# jiashuhan.github.io

Plain HTML/CSS site.

- Pages: `index.html`, `teaching.html`, `research.html`, `cv.html`, `other/index.html`, `blog/index.html`
- Styles: `assets/css/site.css` (colors are variables at the top; dark mode is automatic)
- New blog post: copy `blog/_post-template.html` to `blog/YYYY-MM-slug.html`, write it,
  then add a card to `blog/index.html` (an example is in a comment there).
- When editing, update "Last updated" in each page's footer.
